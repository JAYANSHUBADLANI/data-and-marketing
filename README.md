# Data & Marketing

Two verticals, one author. Data science and analytics on one side, marketing on the other.

Live at: https://jayanshubadlani.github.io/data-and-marketing

Posts go under `_posts/`, tagged with `categories: [data]` or `categories: [marketing]` in the front matter so they show up on the matching section page.

## Running locally

```
bundle install
bundle exec jekyll serve
```
